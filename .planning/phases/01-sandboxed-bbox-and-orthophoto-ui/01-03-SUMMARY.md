## Deviations from Plan

### Auto-fixed implementation issues

- The initial timeout test attached its rejection assertion after fake time advanced, causing Vitest to report the expected timeout as unhandled. The rejection consumer now attaches before clock advancement without weakening the assertion.
- Tests needed Node's `readFileSync` while the browser tsconfig intentionally excludes the unapproved `@types/node`; the runtime builtin import has a narrow documented typecheck suppression rather than adding a package.
- Conformance exposed Vite's generated module-preload fetch authority. The unnecessary polyfill was disabled in Vite config; fresh build, inventory, conformance, and Paja tests reran green.
- The first Paja locator assumed a navigated preview frame. Observed Paja 0.8.0 instead injects target bytes into `about:srcdoc`; the harness now validates stable iframe metadata and proves proxy-response SHA equals dist SHA.

### Runtime recovery

- The Task 1 executor timed out after the RED commit and GREEN file creation; Git plus direct gates reconciled the state and the GREEN commit was completed by the parent.
