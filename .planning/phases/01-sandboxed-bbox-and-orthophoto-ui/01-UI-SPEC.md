# Phase 1 — UI Design Contract

> Visual and interaction contract for the Sandboxed Bbox and Orthophoto UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Consumed by the planner and executor as the visual source of truth.
>
> **Design intent:** an intentionally compact, map-dominant technical cartography workbench. The map and the selected rectangle are the primary visual anchor; the canonical request preview / status panel is the secondary anchor. No marketing-page layout, no decorative complexity, no animation dependence, no military/surveillance styling. Everything renders from the single-file production artifact with zero remote fonts, icons, images, scripts, or styles.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — hand-authored semantic HTML + CSS custom-property tokens + small component classes |
| Preset | not applicable |
| Component library | none (no shadcn, no Radix, no third-party component registry) |
| Icon library | none — inline SVG authored in-repo (≤ 8 glyphs: draw, clear, retry, coordinates, warning, info, undo, source dot); no icon font, no remote icon pack |
| Font | System UI sans stack for all UI text; system monospace stack for coordinate/value presentation. No `@font-face`, no network fonts. |

Font stacks (design tokens, exact):

```css
--font-ui:   system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans", sans-serif;
--font-mono: ui-monospace, "SF Mono", "Cascadia Mono", "Noto Sans Mono", Menlo, Consolas, monospace;
```

`--font-mono` is used only for coordinate values, area values, and the canonical request preview value column. It uses the same declared sizes and weights as `--font-ui` — a family change, never a new size or weight.

**Registry safety gate:** not applicable — no third-party registry, no shadcn.

**Sandbox/transport constraint (binding):** the production `dist/index.html` contains all CSS inline/bundled. `verify-dist` already rejects remote executable/style/font/worker references (01-RESEARCH.md Production Artifact Assertions); this contract adds: no remote **icon or decorative image** references either. Map basemap/orthophoto bytes reach the UI through exactly these transports and no others:

1. **Primary — feature-detected shell resource path.** The shell resource capability, feature-detected through the single shell adapter (SBOX-03), is the only live-imagery transport.
2. **Test-only — audited bundled fixture.** The audited bundled fixture serves tests and Gate-G2-open demo states only; it is never presented or served as live imagery and always carries the TEST FIXTURE labeling defined in the Copywriting Contract.
3. **Conditional — local authenticated fallback.** A local shell/backend resource surface exists only after the documented SBOX-02/OPS-01 fallback trigger (built-artifact sandbox smoke blocked > 30 minutes, activation recorded in the fallback ledger — which fallback, when, why). When it exists it: (a) is reached exclusively through the same sole feature-detected adapter — the UI gains no second transport code path; (b) binds loopback only by default; (c) requires a scoped local auth token on every endpoint; (d) enforces a narrow origin/capability allowlist; (e) keeps the token out of committed and browser assets — provisioned locally at runtime, never checked in, never embedded in `dist`; and (f) fails closed — missing or wrong auth, and any unapproved non-loopback exposure, are refused, surfacing in the UI as the denied state, never as a degraded-open preview.

The "local fallback" copy string, LOCAL FALLBACK badge, and "— local fallback" source-row suffix in this contract render only while transport 3 is active per its recorded activation; they never appear otherwise.

Exceptions (all explicit, none are spacing tokens):

- **2px** border width for focus ring and selection rectangle stroke; **1px** for hairline borders/dividers.
- Panel fixed width **320px** on desktop (layout dimension, not a spacing token).

## Typography

Exactly four sizes, exactly two weights, for the entire Phase 1 UI. No other font size or weight may appear in CSS.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Caption (attribution, badges, field hints, fixed-default annotations) | 12px | 400 | 1.4 |
| Body (all controls, labels, messages, coordinate values, buttons) | 14px | 400 (600 for button labels and emphasized status words) | 1.5 |
| Heading (panel section titles, empty-state heading, toast title) | 16px | 600 | 1.2 |
| Display (area readout value, e.g. "12.4 km²") | 20px | 600 | 1.2 |

Rules:

- Weights allowed: **400** and **600** only.
- Monospace values (coordinates, area digits, request DTO values) use the same size/weight as their role — Body 14px/400 for DTO values, Display 20px/600 for the area readout.
- No italics, no letter-spacing tricks, no all-caps body text. Badges ("TEST FIXTURE", "OFFLINE", "LOCAL FALLBACK") are the single uppercase exception: Caption size at weight 600 with 4px horizontal padding — still within the four declared sizes and two declared weights.

## Color

Dark technical-cartography theme. The 60/30/10 allocation applies to application chrome; map raster content (tiles/orthophoto) is external imagery and sits inside the map canvas, framed by the 60% surface.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#14171B` | App background, map frame, toolbar background, page chrome |
| Secondary (30%) | `#1F242B` | Request preview/status panel, cards, banners, inputs, toast surface |
| Accent (10%) | `#58B8E8` | See reserved list below — nothing else |
| Destructive / Error | `#FF8A80` (text/border) on `#3B2224` (error surface) | Semantic error states only |
| Text primary | `#E6EAEF` | All primary text (13:1+ on dominant) |
| Text secondary | `#9AA4B0` | Captions, hints, attribution (≥ 4.5:1 on secondary surface) |
| Border / divider | `#333A44` | 1px hairlines, input borders, panel edges |

**Accent reserved for (exhaustive — never "all interactive elements"):**

1. The primary **"Draw bounding box"** CTA (filled accent, label in `#0C1014`).
2. The **active selection rectangle** stroke and its corner handles on the map (2px stroke, 12% opacity accent fill).
3. The **focus ring** (2px `outline` in accent, 4px offset, `:focus-visible` everywhere).
4. The **current-source indicator dot** — accent **only when** the active transport is a live trusted shell-resource source. Fixture, fallback, unavailable, and offline indicators use neutral text/border colors, never accent — accent must never dress up a non-live source as live.

**Destructive/error color reserved for:** invalid-bbox field borders and messages, area-too-large message, antimeridian rejection message, resource denied/timeout/failed banners, and the "Clear selection" button treatment (error-colored text/border on neutral surface; not a filled red button). Fixture/offline/degraded labeling is **neutral** (text + badge + glyph), not error-colored and not accent-colored: degraded is honest, not alarming.

All text/background pairs above meet WCAG 2.2 AA (≥ 4.5:1 normal text, ≥ 3:1 for the 20px/600 Display role and non-text UI boundaries). Accent on dominant: ≈ 8.6:1. Error text on dominant: ≈ 8:1.

## Copywriting Contract

All CTAs are specific verb + noun. Banned: Submit, OK, Save, Cancel, Click Here. Placeholders in `{braces}` are filled from checked-in non-secret configuration (fixed v1 defaults, configured area limit, configured timeout, source policy record).

### Buttons / CTAs

| Element | Copy |
|---------|------|
| Primary CTA (accent) | **Draw bounding box** |
| Stop drawing (secondary, visible while drawing; Escape equivalent) | **Stop drawing** |
| Coordinate entry toggle | **Enter coordinates** |
| Coordinate apply | **Apply coordinates** |
| Clear (destructive treatment) | **Clear selection** |
| Undo (in toast) | **Restore selection** |
| Preview retry | **Retry preview** |

### State copy (exact user-facing strings)

| Element | Copy |
|---------|------|
| First-run empty state — heading | **No area selected** |
| First-run empty state — body | Draw a rectangle on the map or enter coordinates to define the terrain area for this request. |
| Draw mode helper (pointer) | Click and drag on the map to draw the rectangle. Press Escape or choose Stop drawing to exit. |
| Draw mode helper (touch) | Touch and drag on the map to draw the rectangle. |
| Edit state helper | Drag a corner handle to resize or drag inside the rectangle to move it. Area and request preview update when you release. |
| Clear — undo toast | **Selection cleared.** [Restore selection] — toast persists 10 seconds (timer pauses on hover/focus; persists until dismissed under reduced motion or when focused by keyboard). |
| Success / ready state | **Selection ready.** {AREA} km² — the request preview below reflects this selection. |
| Preview loading | Loading preview for the selected area… |
| Source attribution (map overlay, always visible) | Basemap © OpenStreetMap contributors · Imagery © {SOURCE_ATTRIBUTION} — {LICENSE_ID} |
| Fixed defaults (request panel rows) | Resolution: **{RES_M} m/px** — fixed for v1 · Output: **{OUTPUT_MIME}** — fixed for v1. Helper caption: These values are set by the service and cannot be changed in this version. |
| Invalid bbox — malformed / non-finite | Coordinates must be finite decimal degrees. Check each field for empty values or stray characters. |
| Invalid bbox — out of range | Longitude must be between −180 and 180, latitude between −90 and 90. |
| Invalid bbox — order / zero area | West must be less than east, and south must be less than north. |
| Area too large | Selected area is {AREA} km², over the {MAX_AREA_KM2} km² limit for this service. Draw a smaller rectangle or lower the coordinates' span. |
| Antimeridian rejection | Selections crossing the ±180° line are not supported in this version. Draw a rectangle that stays on one side of the antimeridian. |
| Resource denied | Imagery access was denied by the shell. Your selection and request preview remain valid. Grant the resource capability in the shell, then choose **Retry preview**. |
| Resource timeout | The imagery source did not respond within {TIMEOUT_S} seconds. Your selection is unchanged. Choose **Retry preview** to try again. |
| Preview failed (generic — any failure that is not denied and not timeout) | The imagery preview could not be loaded. Your selection and request preview remain valid. Choose **Retry preview** to try again. |
| Source unavailable (no trusted source configured) | No trusted imagery source is active. Bounding-box selection and the request preview work normally; the orthophoto preview stays off until a source is approved. |
| Fixture mode (badge + body, never accent-colored) | Badge: **TEST FIXTURE** · Body: This image is a bundled test fixture, not live orthophoto imagery of the selected area. |
| Fallback transport label (only while the recorded SBOX-02/OPS-01 local fallback transport is active — Design System sandbox/transport constraint, transport 3) | Preview served through the local authenticated fallback, not the shell resource path. |
| Offline / degraded | You appear to be offline. Map tiles and imagery may be missing or stale; selection tools and the request preview still work. |
| Request preview panel title | **Request preview** |
| Request preview bbox label | Bounding box (W, S, E, N — EPSG:4326) |
| Request preview source row | Source: {SOURCE_NAME} — live / — test fixture / — local fallback / — unavailable (exactly one suffix, matching the active transport state) |

**Destructive action policy — Clear selection:** clear executes immediately (no blocking confirmation dialog) and shows the 10-second **Restore selection** undo toast. Rationale: a bbox is cheap to recreate and a modal would punish the common case; undo is the reversible-by-default approach. The cleared bbox is retained in memory until the toast expires. Clear also aborts/invalidates any in-flight preview request (research pattern 3).

## Layout & Responsive Contract

Map-dominant workbench, two named breakpoints:

**Desktop / wide (≥ 900px):**
- Two-region layout: map canvas fills all remaining width and full viewport height; fixed **320px** right panel (Secondary surface) containing, top to bottom: selection status + area readout (Display role), coordinate fields (collapsed behind **Enter coordinates** by default), orthophoto preview pane (4:3 box, letterboxed), request preview DTO, source/transport status row.
- Compact toolbar overlaid at the top-left of the map (Dominant surface, md padding): **Draw bounding box**, **Enter coordinates**, **Clear selection**. Attribution line pinned bottom-right of the map at Caption size, always visible, never overlapped.
- No page scroll at ≥ 900px on ≥ 720px-tall viewports; the panel scrolls internally if needed.

**Narrow / mobile (< 900px):**
- Single column: map on top at `min(55vh, 480px)` height (minimum 320px), panel below, document scrolls.
- Toolbar buttons keep 44px height, full-width row under the map or overlaid top of map with sm gaps.
- Coordinate fields render as a 2×2 grid (West/East, South/North) with md gaps; each input ≥ 44px tall.
- Minimum supported width: **320px** with no horizontal scroll and no clipped copy.

**Touch behavior:** one-finger drag inside draw mode draws; outside draw mode one-finger drag pans the map (drawing is never the default gesture — it must be explicitly armed via **Draw bounding box**). Pinch zooms. Handles use 44×44 hit regions. No hover-only affordances: every hover hint has a visible or focusable equivalent.

**High-DPI:** map canvas renders at `devicePixelRatio`; hairlines use real 1px borders (no fractional-px hacks); inline SVG glyphs scale losslessly. Visual smoke includes a 2× DPR capture.

## Interaction State Machine

Two orthogonal machines; the planner turns each transition into a task/test.

**Selection machine:**

```text
EMPTY ──Draw bounding box──▶ DRAWING ──release──▶ validate ──▶ SELECTED_VALID
  ▲                            │ Escape/Stop drawing               │
  │                            ▼                                   ▼
  │                          EMPTY                    SELECTED_INVALID (banner, error stroke on
  │                                                    rectangle in error color, preview blocked)
  │ toast expires (10 s)
CLEARED_UNDOABLE ◀──Clear selection── SELECTED_* / EDITING
  │ Restore selection
  └────────▶ previous SELECTED_* state (bbox + preview correlation restored)

SELECTED_* ──handle/interior drag──▶ EDITING ──release──▶ validate ──▶ SELECTED_VALID | SELECTED_INVALID
EMPTY | SELECTED_* ──Apply coordinates──▶ validate ──▶ SELECTED_VALID | field-level errors (state unchanged)
```

- Exactly zero or one rectangle exists. Starting a new draw while one exists replaces it on successful completion (announced), never silently mid-draw.
- Validation order and clauses per MAP-04; the first failing clause's copy renders (malformed → range → order → antimeridian → area limit).

**Preview machine (per selection revision `r`):**

```text
SOURCE_NONE ──────────────────────────▶ "Source unavailable" panel state (terminal until config changes)
SELECTED_VALID(r) ──400 ms settle──▶ LOADING(r) ──bytes──▶ READY(r) [live | fixture | local-fallback]
LOADING(r) ──capability absent──▶ DENIED       (Retry preview)
LOADING(r) ──deadline exceeded──▶ TIMEOUT      (Retry preview)
LOADING(r) ──other failure────▶ FAILED        (exact "Preview failed (generic)" copy, Retry preview)
any response where r < current revision ──▶ discarded (never rendered)
Clear selection ──▶ abort in-flight request; preview pane returns to empty-state copy
OFFLINE flag (navigator/online + failed basemap heuristics) overlays any state with the offline banner;
it degrades honestly and never blocks bbox interaction or the request preview DTO.
```

When no trusted source is active (`SOURCE_NONE`), bbox drawing, editing, area, and the canonical request preview remain fully functional; the request preview source row reads "— unavailable".

State→copy binding: `DENIED`, `TIMEOUT`, and `FAILED` each render exactly their own Copywriting Contract string. `FAILED` renders only the "Preview failed (generic)" copy — it never uses the denied or timeout wording, because the failure is neither a capability denial nor a deadline expiry; the selection and request preview remain valid and **Retry preview** is its action. `READY(fixture)` is the test-only audited bundled fixture, always labeled TEST FIXTURE, never presented as live. `READY(local-fallback)` is reachable only while the recorded SBOX-02/OPS-01 local fallback transport (Design System sandbox/transport constraint, transport 3) is active, and still arrives through the sole feature-detected adapter.

## Accessibility Contract

- **Keyboard-only MAP-01/02 path (required):** the coordinate field group + **Apply coordinates** is the guaranteed keyboard mechanism to create and edit a bbox; **Clear selection** and **Restore selection** are standard buttons. This alone satisfies draw/edit/clear without pointer use. Map-canvas keyboard drawing is an optional enhancement, not the accessibility path. When the rectangle overlay has focus, Arrow keys nudge the box by 1% of its span (Shift+Arrow: 10%) — enhancement, tested if implemented.
- **Focus:** `:focus-visible` 2px accent outline, 4px offset (on-scale, = `--space-xs`), on every interactive element including map canvas, handles, toast action, and banner buttons. Tab order: skip link → toolbar → map canvas → panel (coordinates → preview actions → DTO region).
- **Screen reader announcements:** one `aria-live="polite"` status region announces: selection set/updated ("Bounding box set. West {w}, south {s}, east {e}, north {n}. Area {AREA} square kilometers."), clear/restore, preview loading/ready, and transport changes. Validation and transport errors render in a `role="alert"` region (assertive). The undo toast is `role="status"` with its action reachable via Tab.
- **Labels/semantics:** real `<label>` on each coordinate input; DTO panel is a `<dl>`; badges carry visually hidden expansions (e.g. "Test fixture image, not live orthophoto"). The source indicator never relies on color alone — the text suffix (live / test fixture / local fallback / unavailable) is always present.
- **Reduced motion:** `prefers-reduced-motion: reduce` disables the toast fade and the loading spinner animation (static "Loading preview…" text remains) and makes the undo toast persistent until dismissed. No information or function depends on animation in any mode.
- **Contrast:** all pairs per the Color section; verified by automated contrast check in visual tests. `forced-colors: active` spot-check: focus ring and rectangle stroke fall back to `Highlight`/system colors via `outline` and SVG `stroke` respecting forced-color adjustment.
- **Touch:** 44×44 minimum targets throughout; drawing requires explicit mode arming so panning is never hijacked.

## Motion

- Allowed properties: `opacity` and `transform` only. Durations: 120ms (hover/press feedback) and 200ms (toast/banner enter-leave). Easing: `--motion-ease`.
- The only animations in Phase 1: toast enter/leave fade+4px rise, banner fade-in, loading spinner (CSS rotation on an inline SVG).
- Under `prefers-reduced-motion: reduce`: all three are removed; states appear/disappear instantly; loading shows static text.
- Nothing moves on the map except the user-driven rectangle; no pulsing, no attention animation, no animated map fly-to on selection (jumping the camera would fight direct manipulation).
